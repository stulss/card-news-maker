1. 한 줄 요약

카드툰는 회원가입·로그인이 없고, 사용자가 만든 이미지·문구·작업 내용을 서버로 전송하거나 수집하지 않습니다. 모든 편집은 사용자의 브라우저 안에서 이루어집니다.

3. 처리하는 정보

구분내용저장 위치·보관
사용자가 만든 콘텐츠업로드한 사진, 문구, 슬라이드, 템플릿, 스티커, 캡션 초안, 내보내기 설정사용자의 브라우저 저장소(localStorage·IndexedDB). 서버로 전송하지 않으며 운영자는 접근할 수 없습니다.

쿠키·추적쿠키를 사용하지 않으며, 방문 분석·광고·행동 추적 도구를 넣지 않았습니다.해당 없음

4. 외부 서비스와의 통신

  • 글꼴은 서비스와 함께 제공되어 Google Fonts 등 외부에서 불러오지 않습니다.
  • AI 배경 제거·AI 배경 흐리게(선택 기능)를 처음 사용할 때에만, 사용자의 동의를 받은 뒤 AI 모델 파일(약 25MB)을 huggingface.co(및 라이브러리 파일을 제공하는 cdn.jsdelivr.net)에서 내려받습니다. 이 요청에는 사용자의 사진이 포함되지 않지만, 해당 사업자에게 IP 주소 등 통상적인 접속 정보가 전달될 수 있습니다. 이후 처리는 모두 브라우저 안에서 이루어집니다.
  • 인스타그램 등 SNS에는 사용자가 직접 파일을 올립니다. 이 서비스가 계정에 접근하거나 대신 게시하지 않습니다.

5. 데이터의 확인·삭제

  • 앱의 메뉴 → 내 데이터 → 저장된 모든 데이터 지우기로 이 브라우저의 모든 저장 데이터를 삭제할 수 있습니다.
  • 브라우저의 사이트 데이터 삭제 기능으로도 지울 수 있습니다.
  • 작업을 보관하고 싶다면 메뉴 → 프로젝트 저장으로 내 컴퓨터에 파일을 만들 수 있습니다. 이 파일은 사용자가 직접 관리합니다.

6. 아동

이 서비스는 개인정보를 수집하지 않으므로 연령과 무관하게 이용할 수 있으나, 사진 속 사람의 초상권·저작권은 사용자가 확인해야 합니다(이용 약관 참고).

7. 보안

서비스는 HTTPS로 제공되며, 엄격한 콘텐츠 보안 정책(CSP)과 보안 헤더를 적용합니다. 사용자의 콘텐츠가 서버에 없으므로 서버 측 유출 위험이 없지만, 같은 컴퓨터를 쓰는 다른 사람이 접근할 수 있으므로 공용 PC에서는 사용 후 위 5항의 방법으로 데이터를 지워 주세요.
