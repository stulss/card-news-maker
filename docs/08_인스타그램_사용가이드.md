# 08. 인스타그램에 올리기 — 사용 가이드와 한계 (2026-11-02)

이 앱으로 만든 카드뉴스를 실제 인스타그램 게시물로 올리는 방법과, 앱이 어디까지 도와주는지를 정리한다.

## 1. 규격 요약 (참고용)

아래 수치는 Meta가 공개한 권장값과 업계에서 널리 쓰이는 값이다. 앱 업데이트로 바뀔 수 있으니 **앱의 `IG` 가이드와 실제 업로드 화면에서 한 번 더 확인**할 것.

| 용도 | 권장 크기 | 앱의 화면비 버튼 |
|---|---|---|
| 피드 게시물·캐러셀 | **1080×1350 (4:5)** — 피드에서 가장 크게 보인다 | `4:5` (기본값) |
| 정사각형 피드 | 1080×1080 | `1:1` |
| 프로필 그리드 비율 | 1080×1440 (3:4) | `3:4` |
| 스토리·릴스 커버 | 1080×1920 (9:16) | `9:16` |
| 캐러셀 장수 | 게시물당 **최대 10장** | 슬라이드 목록(최대 10) |
| 캡션 | 최대 2,200자, 해시태그 최대 30개 | 내보내기 창의 캡션 칸에 카운터 |

- **프로필 그리드**: 그리드가 3:4로 바뀐 뒤에는 4:5·1:1 이미지의 좌우가 일부 잘려 보인다. 상단 `IG` 버튼을 켜면 잘리는 영역이 붉은 띠와 점선으로 표시된다(내보낸 파일에는 찍히지 않는다).
- **스토리 안전영역**: 9:16에서 위쪽 약 250px(14%)와 아래쪽 약 340px(20%)는 프로필·답장 UI에 가려질 수 있어 중요한 글자를 피하는 것이 좋다.
- 색 공간은 sRGB(캔버스 기본)이며, 권장 파일은 **JPG 품질 90 이상, 가로 1080px**이다. 내보내기 창의 "JPG · 품질 92 · 가로 1080px 적용" 버튼이 이 설정을 한 번에 적용한다.

## 2. 작업 순서

1. 상단 화면비를 `4:5`로 둔다(새 작업의 기본값).
2. 왼쪽 `갤러리`에서 **캐러셀 세트**(5장·6장)를 고르거나, 빈 슬라이드에서 시작해 캔버스 아래 `＋`로 장을 추가한다(최대 10장). 슬라이드는 복제·순서 변경·삭제가 되고 PageUp/PageDown으로 이동한다.
3. 텍스트·이미지·도형·스티커로 각 장을 꾸민다. 되돌리기(Ctrl+Z)는 다른 슬라이드에서 한 수정도 그 슬라이드로 돌아가 되돌린다.
4. `IG` 가이드로 잘림·가려짐을 확인한다.
5. `내보내기…`(Ctrl+E): 범위 **전체 N장(ZIP)**, 필요하면 **페이지 번호(1 / N)** 와 **워터마크**를 켜고, 캡션·해시태그를 적어 `캡션 복사`.
6. **ZIP 다운로드** → 압축을 풀면 `01.jpg`, `02.jpg`, … 순서대로 파일이 나온다.

## 3. 업로드 방법

- **PC**: instagram.com에서 새 게시물 → 파일을 `01`부터 순서대로 선택 → 복사한 캡션 붙여넣기.
- **휴대폰**: 내보내기 창에 `공유 (인스타 앱)` 버튼이 보이면(파일 공유를 지원하는 모바일 브라우저) 눌러서 공유 창에서 인스타그램을 고른다. 버튼이 없으면 ZIP/이미지를 내려받아 갤러리에서 선택한다.

## 4. 앱이 하지 않는 것 (의도된 한계)

- **인스타그램에 자동으로 게시하지 않는다.** 자동 게시는 Meta Graph API·비즈니스 계정·서버(토큰 보관)가 필요한데, 이 프로젝트는 "서버로 보내지 않는다·로그인 없음" 원칙이라 만들지 않았다.
- 동영상·릴스 편집, 음악, 예약 게시, 해시태그 추천은 없다.
- 슬라이드를 한꺼번에 내보낼 때는 화면을 장마다 전환하며 캡처하므로 진행 창이 뜨고 이미지가 많으면 수 초가 걸린다.
- **저작권은 사용자 책임**이다. 업로드하는 사진·스티커의 사용 권한을 확인할 것. 앱 내장 글꼴은 모두 SIL OFL(상업적 이용 가능)이다.

## 5. 작업 보존

- 작업 중인 슬라이드는 브라우저(IndexedDB)에 1.5초마다 자동 저장되고, 새로고침해도 복원된다. 사진은 저장용으로 변환되어 함께 보관된다. 서버로 전송되지 않는다.
- 처음부터 하려면 명령 팔레트(Ctrl+K) → "새로 시작". 브라우저 데이터를 지우면 저장본도 사라지므로 중요한 작업은 `내 템플릿 → JSON 내보내기`나 ZIP으로 따로 보관한다.

## 6. 검증 결과

헤드리스 Chrome(CDP) 실조작: 5장 세트 적용 → 슬라이드 5개, PageDown 이동, 슬라이드 추가·삭제와 되돌리기, 9:16·4:5 안전영역 띠 표시, 내보내기에서 전체 ZIP 다운로드(`01.jpg`~`05.jpg`, 각 1080×1350 JPEG, ZIP 무결성 통과, 페이지 번호 "2 / 5" 확인), 진행 창 종료·보던 장 복귀, 이미지 업로드 후 새로고침 복원(슬라이드 5개·이미지 유지). 콘솔 오류 0건.
**미검증**: 실제 인스타그램 앱에서의 업로드, 모바일 브라우저의 공유 버튼.
