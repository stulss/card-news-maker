# 07. GitHub 레퍼런스 분석 — photocraft · vectorcraft · lightcraft (2026-11-02)

사용자가 지정한 저장소의 기능을 조사해 이 프로젝트(React + Konva 웹 카드뉴스 메이커)에 맞는 것만 골라 적용한 기록.

## 1. 조사 방법과 한계

| 항목 | 내용 |
|---|---|
| 대상 | `storytold/photocraft`(포토샵류), `storytold/vectorcraft`(일러스트레이터류), `storytold/lightcraft`(라이트룸류) — 모두 Rust·egui·wgpu로 만든 데스크톱 앱(웹 빌드 포함), 라이선스 **MIT OR Apache-2.0** |
| 읽은 것 | 각 저장소 README와 `docs/` 일부(vectorcraft의 `target-app-parity.md`·`ui-parity.md`), crates 폴더 목록. **소스 코드는 읽지 않았다** — 기능→파일 대응은 크레이트 이름에서 추정한 것이다 |
| 코드 재사용 | **없음.** 언어(Rust)가 달라 코드를 가져올 수 없고, 기능 아이디어만 Konva/React로 새로 구현했다 |
| `morluto/rea` | 사용하지 않았다. REA는 바이너리·앱 번들·HAR 등 **배포된 산출물을 역공학**하는 MCP 서버(`npx rea-agents setup`)이며 소스 저장소의 기능 분석에는 맞지 않는다. 설치 시 에이전트(MCP) 설정을 수정하고 외부 도구를 실행할 수 있어, 필요성이 낮은 상태로 설치하지 않았다. 대신 README·문서를 직접 읽었다 |
| 신뢰도 | 각 README의 수치(스타 수·패리티 %)는 저장소 스스로의 주장이다. 긴 문서의 뒷부분은 요약본이었다 |

## 3. 이번에 구현한 것의 코드 위치

- 도형: `src/components/shape/ShapePanel.tsx`, `CanvasStage.tsx`(Ellipse/Star/RegularPolygon, 중심 좌표 도형 보정), `types/canvas.ts`(`shapeType`에 `star`·`triangle` 추가)
- 정렬: `App.tsx`의 `handleAlign`, `PropertiesPanel.tsx`
- 블렌드: `types/canvas.ts`의 `BLEND_MODES`, `templateStore.ts` 검증, 각 Konva 노드의 `globalCompositeOperation`
- 이미지 보정: `ImageLayerNode.tsx`(Konva HSL·Noise·Pixelate 필터), `ImageFilters`
- 원본 비교: `App.isComparingOriginal` → `CanvasStage.originalViewLayerId` → `ImageLayerNode.ignoreFilters`

## 4. 검증

헤드리스 Chrome + CDP 실조작: 채도·색조·입자·모자이크 슬라이더로 캔버스 픽셀 값 변화 확인, 원본 비교 버튼을 누르는 동안 원래 픽셀로 복귀·놓으면 보정 복귀, 블렌드 `multiply` 적용, 도형 6종 추가(Rect·Ellipse·Star·RegularPolygon 노드 확인), 원 정렬(왼쪽 x=0, 가로 가운데 x=540), 원·별 마우스 드래그 좌표 반영, 원 1.5배 변형 시 중심 위치 유지. 콘솔 오류 0건.

## 5. 후속 적용 (같은 날, 사용자 요청 5건)

| 항목 | 구현 | 검증 |
|---|---|---|
| 보정 프리셋 강도 | `PropertiesPanel`의 `scaleFilters` — 숫자 값은 비례 조절, 흑백·세피아는 50% 이상에서 켜짐 | 강도 100→0.4, 200→0.8, 0→필터 없음 확인 |
| 단축키 도움말 | `components/help/ShortcutHelp.tsx` | `?`로 열림(16행)·Esc로 닫힘 |
| 명령 팔레트 | `components/command/CommandPalette.tsx`, `App.buildCommands` — 약 40개 명령, 선택 레이어가 있으면 복제·삭제·정렬 추가 | Ctrl+K → "별" 검색 → Enter로 별 도형 추가 |
| WebP·워터마크 내보내기 | `features/export/exportImage.ts`, `components/export/ExportDialog.tsx` | WebP MIME 확인, 워터마크 켜면 모서리 밝은 픽셀 0→3324, 200%에서 2160×2700, 설정 저장 |
| 눈금자·가이드 | `components/canvas/Rulers.tsx`, `CanvasStage`(가이드 그룹은 내보내기 때 숨김) | 눈금자 2개 표시, 클릭 시 가이드선 생성, 내보내기 후 가이드 복원 |

단축키는 브라우저 기본 동작과 겹치는 것을 피해 정했다(Ctrl+F 대신 Ctrl+K, Ctrl+R 대신 Shift+R).
