# 배포

## 현재 상태

- 운영 주소: https://card-news-maker-beige.vercel.app/
- 배포 대상: Vite 정적 프론트엔드 + Vercel 서버리스 함수 `api/kbo-schedule.ts`
- 환경변수: 없음
- 최신 확인: 배포 화면과 `/api/kbo-schedule?date=2026-08-01`의 정상 응답 확인 완료

## 설정

- 빌드 명령: `npm run build`
- 출력 디렉터리: `dist`
- `api/*.ts`의 상대 import는 컴파일 후 Node ESM 실행을 위해 `.js` 확장자를 명시한다.
- 로컬 개발에서는 `vite.config.ts` 미들웨어가 동일 API 핸들러를 호출한다.

## 배포 전후 검증

1. `npx tsc -b`, `npm run lint`, `npm run build`를 실행한다.
2. 배포 후 운영 URL이 HTTP 200인지 확인한다.
3. 야구 탭에서 날짜를 조회하거나 `/api/kbo-schedule?date=2026-08-01`이 JSON 배열을 반환하는지 확인한다.

과거 배포 500 오류의 원인과 해결은 `docs/트러블슈팅.md`를 참고한다.
