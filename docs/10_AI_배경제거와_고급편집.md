# 10. AI 배경 제거와 고급 편집 기능 (2026-11-02)

## 1. AI 배경 제거

| 항목 | 내용 |
|---|---|
| 사용법 | 이미지를 선택 → 속성 패널 `모양` 섹션의 `✨ AI 배경 제거`(또는 명령 팔레트) → 첫 사용 시 안내에 동의 → 진행률 표시 → 배경이 투명한 PNG로 교체. Ctrl+Z로 되돌림 |
| 처리 위치 | **브라우저 안**(WebAssembly). 사진은 어떤 서버로도 전송되지 않는다 |
| 외부 통신 | 처음 한 번 **모델 파일(약 25MB)을 huggingface.co에서 내려받는다.** 브라우저가 캐시하므로 이후에는 내려받지 않는다. 사진 데이터는 나가지 않는다 |
| 구성 | `@huggingface/transformers` 4.x(Apache-2.0) + `Xenova/modnet`(MODNet, Apache-2.0). 코드는 `features/ai/removeBackground.ts`, 동적 import라서 쓰기 전에는 로드되지 않는다 |
| 한계 | **사람 사진용 모델**이다(인물 외 사물은 결과가 부정확할 수 있음). 긴 변 1536px로 줄여 처리하므로 결과 해상도가 원본보다 낮을 수 있다. 오프라인에서는 첫 실행이 실패한다(오류 안내 표시) |
| 빌드 | 메인 번들 약 671KB(gzip 205KB), AI 코드 약 544KB와 ONNX 런타임 WASM 약 27MB는 별도 파일로 분리되어 AI를 쓸 때만 받는다 |
| 검증 | 실제 인물 사진(360×450)으로 실행 — 26초(모델 내려받기 포함), 투명 42%·불투명 53%, 모서리 알파 0·중앙 254, 머리카락 가닥까지 분리. 되돌리면 원본(blob) 복귀. 오류 0건 |

> "이미지를 서버로 보내지 않는다" 원칙은 유지된다. 예외로 기록할 것은 **모델 파일 내려받기**뿐이며, 사용자의 동의(확인 창) 뒤에만 일어난다.

## 2. 작업 이력 패널
- 왼쪽 레일 `기록`. 목록의 각 단계는 앞뒤 스냅샷을 비교해 자동으로 이름이 붙는다("추가: 도형 별", "이동: 헤드라인", "이미지 보정: …", "슬라이드 추가" 등).
- 클릭하면 그 시점으로 이동하고, 이후 단계는 "취소됨"으로 흐리게 남아 Ctrl+Shift+Z/다시 단계 클릭으로 복원할 수 있다. 새로 수정하면 그 뒤 단계는 사라진다.
- **버그 수정**: 되돌리기 훅이 상태 갱신 함수 안에서 `ref`를 수정해, 개발 모드(StrictMode의 이중 호출)에서 첫 변경이 앞 단계에 합쳐졌다. 병합 정보를 상태에 넣어 갱신 함수를 순수하게 만들었다.

## 3. 텍스트 그라디언트
글자 색 → `그라디언트`: 두 색·각도(선형)·원형·시작/끝 불투명도·프리셋 12종. 글자 상자 전체를 기준으로 채우며(`konvaGradient`), 스타일 복사·갤러리 썸네일에 반영된다.

## 4. 이미지를 도형으로 오리기
이미지 속성 → 모양으로 오리기: 원형·별·삼각형·육각형·하트·말풍선. 이미지 확대·위치(자르기)와 함께 동작하고 테두리는 도형 모양을 따라간다. 오려 낸 결과 위에 보정 필터가 그대로 적용된다.

## 5. 스티커 팩
밈 탭 → 스티커 팩: **배지**(NEW·FREE·HOT·SALE·BEST·1위·마감임박), **말풍선**(헐!·꿀팁·ㅋㅋㅋ·주목!), **강조**(화살표·형광 밑줄·동그라미·체크·물음표·느낌표), **장식**(반짝이·하트·번개·북마크·컨페티). 각각 도형+글자를 한 그룹으로 추가해 함께 움직이고, 색은 속성 패널에서 바꿀 수 있다.

## 6. 남은 후보까지 구현 (같은 날 후속)

### 이미지 뒤집기
이미지 속성 → `↔ 좌우 뒤집기` / `↕ 상하 뒤집기`. Konva의 `scale(-1)` + `offset`으로 상자 위치를 유지한 채 뒤집는다. 크기·회전 변형과 그룹 이동 뒤에도 뒤집힘이 유지되도록 변형 값을 읽을 때 부호를 보존한다(`CanvasStage.readNodeTransform`). SVG·썸네일에도 반영된다.

### 텍스트 곡선
텍스트 속성 → `곡선`(-100 ~ +100): 양수는 아치(∩), 음수는 스마일(∪). 글자를 한 자씩 원호 위에 놓고 접선 방향으로 돌려 비트맵으로 그린 뒤 Image 노드로 보여 준다(`features/design/curvedText.ts`, `CurvedTextNode.tsx`).
- 한 줄·가운데 정렬로 그려지고 줄바꿈은 공백으로 이어진다. 그라디언트·외곽선·그림자·글자 간격이 모두 적용된다.
- 곡선 값을 바꿀 때 호가 잘리지 않도록 상자 높이를 자동으로 맞춘다. 글자 크기·문구를 바꾼 뒤에는 곡선 슬라이더를 다시 움직이면 높이가 맞춰진다.

### SVG 내보내기
내보내기 창 형식에 `SVG`(`features/export/svgExport.ts`). 캡처가 아니라 슬라이드 데이터에서 바로 벡터로 만든다.
- **보존**: 도형(별·삼각형·하트 등)·글자(줄바꿈 계산 포함)·배경/도형/글자 그라디언트·그림자·혼합 모드·회전·이미지 자르기·모양 오리기·뒤집기·테두리·기본 보정(CSS 필터: 밝기·대비·채도·색조·흐림·흑백·세피아). 이미지는 data URL로 내장.
- **미반영**: 비네팅·필름 입자·모자이크, 글꼴 파일(이름만 기록 — 보는 기기에 글꼴이 없으면 대체됨), 워터마크·페이지 번호·크기 배율. 곡선 글자는 이미지로 들어간다.
- 전체 슬라이드는 `01.svg…` ZIP.

### 영역 효과 (AI 선택 계열)
| 효과 | 방식 | 비고 |
|---|---|---|
| **AI 배경 흐리게 (인물 모드)** | MODNet으로 피사체를 찾고, 흐리게 한 원본 위에 또렷한 피사체를 합성 | AI 배경 제거와 같은 모델·동의 절차 |
| **스티커 외곽선** | 투명 배경 PNG의 윤곽에 흰 선을 둘러(얇게·보통·두껍게) 스티커처럼 | AI 없이 캔버스 합성. AI 배경 제거 결과와 같이 쓰면 효과적 |
| **하늘 제거 (간이)** | 맨 윗줄의 하늘색·구름색 픽셀에서 이어진 영역을 투명으로(색 기반 영역 확장) | AI가 아니라 휴리스틱 — 맑은·흐린 낮 하늘에 적합, 노을·밤하늘은 부정확. 뒤에 그라디언트를 깔아 새 하늘 |

## 7. 운영 환경(CSP)에서의 AI

운영 헤더(`vercel.json`)에서 AI가 동작하려면 `script-src`에 `blob:`과 `'wasm-unsafe-eval'`, `connect-src`에 `huggingface.co`·`*.hf.co`·`cdn.jsdelivr.net`이 필요하다. 이 외에는 막혀 있다. 자세한 내용은 `docs/11_상용화_체크리스트.md` §3-3, `docs/트러블슈팅.md` 25번.
