# 검증 안내서

## 어디로 가나요

https://card-news-maker-beige.vercel.app/ 에 접속한다.

## 무엇을 하나요

1. 비율을 선택하고 PNG/JPEG 이미지를 불러온다.
2. 문구를 추가·수정한 뒤 템플릿으로 저장한다.
3. PNG 또는 JPG로 내려받고 화면과 파일의 배치·해상도를 비교한다.

야구 기능은 `야구 카드` 탭에서 날짜를 조회하고 종료 경기를 선택해 카드를 생성한다.

## 무엇이 보이면 통과인가요

- 이미지와 한글 문구가 즉시 캔버스에 표시되고 이동·크기·스타일 변경이 반영된다.
- 1:1, 4:5, 9:16 결과가 각각 1080×1080, 1080×1350, 1080×1920으로 저장된다.
- 템플릿은 새로고침 후 유지되고 정상 JSON은 복원되며 잘못된 JSON은 기존 데이터를 보존한 채 거부된다.
- 야구 카드는 양 팀 로고·점수·날짜·구장이 잘림 없이 표시된다.

## 안 될 때

- GIF 등 미지원 형식은 PNG/JPEG로 변환해 다시 시도한다.
- 템플릿 JSON 오류는 파일의 `version`, `templates`, 레이어 필수 필드를 확인한다.
- 야구 조회 실패 시 잠시 뒤 재시도하거나 화면의 직접 입력 폴백을 사용한다.
- 배포 API가 500이면 `api/*.ts` 상대 import의 `.js` 확장자와 Vercel 로그를 확인한다.
