# 검증 안내서

## 어디로 가나요

https://card-news-maker-beige.vercel.app/ (로컬은 `npm install` 후 `npm run dev`)

## 무엇을 하나요

1. **기본 편집**: 화면비(1:1·4:5·9:16)를 고르고 PNG/JPEG/WebP 이미지를 올린 뒤 텍스트를 추가·수정한다.
2. **빠른 시작**: 왼쪽 `갤러리`에서 템플릿을 눌러 적용하고, `밈`에서 자막 프리셋·이모지 스티커·내 스티커(업로드)를 추가한다.
3. **다듬기**: 레이어를 끌어 순서를 바꾸고(⋮⋮ 손잡이), 다중 선택 후 그룹으로 묶어 함께 이동한다. 도형 탭에서 도형을 추가하고 속성 패널에서 정렬·혼합 모드를 쓴다.
4. **이미지 보정·자르기**: 이미지를 선택해 프리셋(강도 슬라이더)·밝기·대비·채도·색조·입자·모자이크를 조절하고, `캔버스에서 직접 자르기`로 끌어서 위치·휠로 확대한다. "누르는 동안 원본 보기"로 비교한다.
5. **되돌리기·단축키**: Ctrl+Z / Ctrl+Shift+Z, `?`로 단축키 도움말, Ctrl+K로 명령 팔레트, Shift+R로 눈금자(눈금자 클릭 → 가이드선).
6. **캐러셀·인스타**: 갤러리의 `캐러셀 5장 세트`를 적용하고 캔버스 아래 슬라이드 목록에서 장을 추가·복제·이동한다. `IG` 버튼으로 안전영역을 확인하고, `내보내기…`에서 `전체 N장(ZIP)`·페이지 번호·"JPG 92"를 골라 내려받는다. 새로고침 후 작업이 복원되는지도 본다.
7. **그래픽**: 아무것도 선택하지 않고 속성 패널에서 배경 그라디언트 프리셋을 눌러 보고, `도형`에서 "그라디언트로 추가"를 켠 채 하트를 넣어 각도·그림자를 바꾼다. `텍스트` 탭의 "형광펜"·"배지"가 도형+글자 그룹으로 들어오는지, 상단 ☀/☾로 테마가 바뀌는지 확인한다.
8. **참고 앱에서 가져온 기능**: 빈 작업에서 시작 카드가 보이는지, 이미지에 `비네팅`·`시네마` 프리셋을 적용하는지, 도형에 `네온 보라` 그림자를 주고 ⎘로 복사해 다른 도형에 ⇩로 붙여넣는지, `Shift+G`로 격자가 순환하는지, 속성 섹션 제목을 눌러 접히는지 확인한다.
9. **저장**: 템플릿으로 저장(내 템플릿) 후 새로고침해 유지되는지 확인하고, `내보내기…`(Ctrl+E)에서 형식(PNG/JPG/WebP)·품질·크기(50/100/200%)·워터마크를 정해 내려받는다.

## 무엇이 보이면 통과인가요

- 이미지와 한글 문구가 즉시 캔버스에 표시되고 이동·크기·스타일 변경이 반영되며, 드래그 중 분홍 정렬 가이드가 나타난다.
- 1:1, 4:5, 9:16 결과가 각각 1080×1080, 1080×1350, 1080×1920으로 저장되고(크기 100% 기준), 200%에서는 2배 해상도가 된다.
- 내보내기 창이 형식별 예상 용량을 보여 주고, 워터마크를 켜면 미리보기 모서리에 글자가 나타난다. 눈금자 가이드선은 파일에 찍히지 않는다.
- ZIP에 `01.jpg`부터 장 수만큼 들어 있고 각 파일이 선택한 크기(예: 1080×1350)이며, 페이지 번호를 켰다면 하단 가운데에 "n / N"이 찍힌다. `IG` 가이드와 눈금자 가이드선은 파일에 찍히지 않는다.
- 그라디언트 배경·도형이 내보낸 파일에도 그대로 나온다(미리보기의 좌우·상하 색이 다름). 하트 등 벡터 도형을 키워도 위치가 어긋나지 않는다.
- 내보내기에서 `로고 이미지` 워터마크를 켜면 미리보기 모서리에 로고가 나타나고 삭제하면 사라진다. 격자·가이드는 파일에 찍히지 않는다.
- 새로고침 또는 탭을 닫았다 열어도 슬라이드와 업로드한 사진이 그대로 복원된다.
- 템플릿은 새로고침 후 유지되고 정상 JSON은 복원되며 잘못된 JSON은 기존 데이터를 보존한 채 거부된다.
- 그룹의 레이어를 하나만 끌어도 모두 같이 움직이고, Ctrl+Z 한 번에 원위치로 돌아온다.
- 보정 프리셋 강도를 0%로 내리면 보정이 사라지고 200%에서 효과가 두 배로 강해진다(흑백·세피아는 50% 이상에서 켜짐).

## 안 될 때

- GIF 등 미지원 형식은 PNG/JPEG/WebP로 변환해 다시 시도한다.
- 템플릿 JSON 오류는 파일의 `version`, `templates`, 레이어 필수 필드를 확인한다.
- WebP 저장이 안 되면 해당 브라우저가 WebP 인코딩을 지원하지 않는 것이다(PNG/JPG 사용).
- 글꼴이 안 바뀌면 네트워크로 Google Fonts를 불러오지 못한 것이다(새로고침).
- 내 스티커 저장 공간이 부족하다는 안내가 나오면 안 쓰는 스티커를 삭제한다.
