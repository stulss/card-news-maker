# 기획 및 구현 구조

> 2차 고도화(2026-11-02) 기준. 1차(야구 탭 포함) 설계는 git 이력 `9c362ac`에 남아 있다.

## 제품 목표

로그인 없이 이미지·도형·이모지·스티커와 한글 문구를 조합해 카드뉴스·밈을 만들고 PNG/JPG/WebP로 내려받는
브라우저 도구다. 템플릿 갤러리(42종)·밈 자막 프리셋으로 빠르게 시작하고, 레이어·그룹·정렬·보정으로 다듬는다.

## 구현 구조

- 프론트엔드: React 19 + TypeScript + Konva + Vite (정적 빌드, **백엔드 없음**)
- 상태: React 상태 + `localStorage`(내 템플릿·내 스티커·내보내기 설정·캡션) + `IndexedDB`(작업 자동 저장). 작업 단위는 `Deck`(슬라이드 최대 10장), 되돌리기는 `features/history/useProjectHistory.ts`(덱 스냅샷 방식)
- 운영 품질(v1.0.0): 글꼴 자체 호스팅(`@fontsource`, 외부 요청 0건), 보안 헤더·CSP(`vercel.json`), PWA(`manifest`·`sw.js`), `ErrorBoundary`, 프로젝트 파일 저장/열기, 빌드 시 라이선스 게이트, Vitest·Playwright·GitHub Actions CI. 상세는 `docs/11_상용화_체크리스트.md`.
- 제작 보강(v1.1.0): 브랜드 키트(`features/brand`), 요소(`features/elements` — QR·차트, 브라우저에서 그려 이미지 레이어로 삽입), 도형 5종, 갤러리 42종. 범위 선별 기준은 PRD 52장.
- 개인정보: 업로드 이미지·스티커는 브라우저 안에서만 처리하며 서버로 전송하지 않음. AI 배경 제거도 브라우저 안(WASM)에서 실행하고, **모델 파일만** 처음 한 번 외부(huggingface.co)에서 내려받는다(동의 후).
- 내보내기: 미리보기 Konva Stage를 원본 크기·배율 1로 임시 전환해 PNG로 캡처한 뒤(`pixelRatio`로 50/100/200%),
  `features/export/exportImage.ts`가 워터마크를 얹고 PNG/JPG/WebP로 다시 인코딩

## 그래픽 구조

레이어는 텍스트·이미지·도형 세 종류이며 배경과 도형은 그라디언트를 가질 수 있다. 도형은 Konva 기본 도형(사각형·타원·별·삼각형)과 100×100 SVG 경로(하트·말풍선 등)로 그린다. 상세는 `docs/09_디자인_가이드.md`.

## 인스타그램 캐러셀 흐름

슬라이드 여러 장을 한 덱으로 편집하고, 내보낼 때 슬라이드를 차례로 화면에 올려 캡처해 ZIP으로 묶는다(오프스크린 렌더러를 따로 만들지 않아 화면과 파일이 같다). 자세한 사용법은 `docs/08_인스타그램_사용가이드.md`.

## 화면 구성

상단바(되돌리기·화면비·배경색·눈금자·명령 팔레트·단축키·내보내기) · 왼쪽 도구 레일(이미지/텍스트/갤러리/도형/요소/브랜드/밈/내 템플릿/레이어/기록) · 상단 ☰ 메뉴(프로젝트 저장·열기, 데이터 삭제, 약관) ·
서랍 패널 · 캔버스(줌·눈금자·가이드) · 오른쪽 속성 패널(텍스트·이미지 보정/자르기·도형·정렬·혼합 모드·투명도).
900px 이하에서는 도구 레일이 하단 바, 속성 패널이 바텀시트로 바뀐다.

## 핵심 설계 결정

1. 미리보기와 내보내기가 같은 Stage를 사용해 화면·파일 차이를 구조적으로 방지한다.
2. 템플릿 JSON은 전체 검증 후 `localStorage`와 React 상태를 함께 교체한다. 선택 필드(필터·자르기·그림자·혼합 모드·그룹)도 범위를 검증한다.
3. 블렌드 모드는 화이트리스트(`BLEND_MODES`)만 허용한다(임의 값으로 아래 레이어가 지워지는 것 방지).
4. 레이어 상태는 항상 불변 갱신한다(되돌리기 스냅샷 오염 방지).
5. 수익화·계정·클라우드 저장·협업 편집은 범위에서 제외한다. 야구 탭·KBO 프록시는 2차에서 삭제했다.

상세 요구사항은 `PRD.md`(45장이 2차 기능), 레퍼런스 분석은 `docs/07_레퍼런스_분석.md`, 결정 이력은 `작업내역_체크리스트.md` §5를 기준으로 한다.
