# 기획 및 구현 구조

## 제품 목표

로그인 없이 이미지와 한글 문구를 조합해 카드뉴스·밈을 만들고 PNG/JPG로 내려받는 브라우저 도구다.
일반 카드와 KBO 경기 결과 카드는 이미지 소스만 다르고 편집기·레이어·템플릿·내보내기를 공유한다.

## 구현 구조

- 프론트엔드: React 19 + TypeScript + Konva + Vite
- 상태: React 상태와 `localStorage`; 별도 상태관리 라이브러리 없음
- 백엔드: `GET /api/kbo-schedule?date=YYYY-MM-DD` 서버리스 함수 1개
- 개인정보: 업로드 이미지는 브라우저 안에서만 처리하며 서버로 전송하지 않음
- 내보내기: 미리보기 Konva Stage를 원본 크기·배율 1로 임시 전환해 정확한 픽셀 크기로 캡처

## 핵심 설계 결정

1. 미리보기와 내보내기가 같은 Stage를 사용해 화면·파일 차이를 구조적으로 방지한다.
2. 템플릿 JSON은 전체 검증 후 `localStorage`와 React 상태를 함께 교체한다.
3. 야구 데이터는 KBO 원본을 서버에서 `KboGame`으로 정규화해 프론트와 원본 형식을 분리한다.
4. 구단 로고는 실제 종횡비를 메타데이터에 기록하고 공통 영역 안에 contain 배치한다.
5. 수익화·계정·클라우드 저장·협업 편집은 과제 범위에서 제외한다.

상세 요구사항은 `PRD.md`, 실제 결정 이력은 `작업내역_체크리스트.md` §5를 기준으로 한다.
