# 기획 및 구현 구조

> 2차 고도화(2026-11-02) 기준. 1차(야구 탭 포함) 설계는 git 이력 `9c362ac`에 남아 있다.

## 제품 목표

로그인 없이 이미지·도형·이모지·스티커와 한글 문구를 조합해 카드뉴스·밈을 만들고 PNG/JPG/WebP로 내려받는
브라우저 도구다. 템플릿 갤러리(20종)·밈 자막 프리셋으로 빠르게 시작하고, 레이어·그룹·정렬·보정으로 다듬는다.

## 구현 구조

- 프론트엔드: React 19 + TypeScript + Konva + Vite (정적 빌드, **백엔드 없음**)
- 상태: React 상태 + `localStorage`(내 템플릿·내 스티커·내보내기 설정). 되돌리기는 `features/history/useProjectHistory.ts`(프로젝트 스냅샷 방식)
- 개인정보: 업로드 이미지·스티커는 브라우저 안에서만 처리하며 서버로 전송하지 않음
- 내보내기: 미리보기 Konva Stage를 원본 크기·배율 1로 임시 전환해 PNG로 캡처한 뒤(`pixelRatio`로 50/100/200%),
  `features/export/exportImage.ts`가 워터마크를 얹고 PNG/JPG/WebP로 다시 인코딩

## 화면 구성

상단바(되돌리기·화면비·배경색·눈금자·명령 팔레트·단축키·내보내기) · 왼쪽 도구 레일(이미지/텍스트/갤러리/도형/밈/내 템플릿/레이어) ·
서랍 패널 · 캔버스(줌·눈금자·가이드) · 오른쪽 속성 패널(텍스트·이미지 보정/자르기·도형·정렬·혼합 모드·투명도).
900px 이하에서는 도구 레일이 하단 바, 속성 패널이 바텀시트로 바뀐다.

## 핵심 설계 결정

1. 미리보기와 내보내기가 같은 Stage를 사용해 화면·파일 차이를 구조적으로 방지한다.
2. 템플릿 JSON은 전체 검증 후 `localStorage`와 React 상태를 함께 교체한다. 선택 필드(필터·자르기·그림자·혼합 모드·그룹)도 범위를 검증한다.
3. 블렌드 모드는 화이트리스트(`BLEND_MODES`)만 허용한다(임의 값으로 아래 레이어가 지워지는 것 방지).
4. 레이어 상태는 항상 불변 갱신한다(되돌리기 스냅샷 오염 방지).
5. 수익화·계정·클라우드 저장·협업 편집은 범위에서 제외한다. 야구 탭·KBO 프록시는 2차에서 삭제했다.

상세 요구사항은 `PRD.md`(45장이 2차 기능), 레퍼런스 분석은 `docs/07_레퍼런스_분석.md`, 결정 이력은 `작업내역_체크리스트.md` §5를 기준으로 한다.
