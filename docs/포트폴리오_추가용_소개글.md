# 포트폴리오 소개글

## 한 줄 소개

React·TypeScript·Konva로 만든, 서버 없이 브라우저에서 동작하는 카드뉴스·밈 편집기입니다.

## 소개

이미지 업로드, 한글 문구 편집, 레이어·그룹 관리, 3가지 화면비, PNG/JPG/WebP 고해상도 내보내기(워터마크·용량 예상),
템플릿 CRUD·JSON 이동 기능을 구현했습니다. 업로드 이미지와 스티커는 서버로 보내지 않고 브라우저에서만 처리합니다.
2차 고도화에서는 실행 취소/다시 실행, 드래그 정렬 스냅 가이드, 줌·눈금자·가이드선, 이미지 보정·직접 자르기,
도형·정렬·혼합 모드, 밈 자막 프리셋, 템플릿 갤러리 20종, 명령 팔레트와 단축키 도움말을 추가했습니다.
이후 상용화 수준의 운영 품질(자체 호스팅 글꼴로 외부 요청 0건, CSP 등 보안 헤더, PWA, 프로젝트 파일 저장/열기, 개인정보·약관·오픈소스 라이선스 고지,
빌드 시 라이선스 게이트, Vitest·Playwright·GitHub Actions CI)을 갖추고, Canva 등을 참고해 카드뉴스 제작에 맞는 기능(브랜드 키트, QR·차트 요소,
도형·템플릿 42종)만 선별해 추가했습니다. 서비스 이름은 "카드툰"입니다.
GitHub의 오픈소스 에디터 3종(PhotoCraft·VectorCraft·LightCraft)의 기능을 분석해 카드뉴스에 맞는 것만 골라 Konva로 새로 구현했습니다.

화면과 결과 파일이 달라지는 문제를 막기 위해 미리보기와 내보내기가 같은 Konva Stage를 사용하도록 설계했고,
잘못된 템플릿 JSON은 전체 검증 후 원자적으로 거부해 기존 작업을 보존합니다. 임의 블렌드 모드 같은 위험한 값은
화이트리스트로 막았습니다. Vercel 배포와 브라우저(CDP) 자동 검증까지 진행했습니다.

- 기술: React 19, TypeScript, Konva, Vite, Vercel(정적 호스팅)
- 배포: https://card-news-maker-beige.vercel.app/
- 핵심 경험: 캔버스 렌더링, 불변 상태 기반 되돌리기, 방어적 데이터 검증, 반응형·터치 편집 UX
- 1차 제출 시점에는 KBO 경기 결과 카드 자동 생성(서버리스 크롤링 프록시) 기능이 있었고, 2차에서 범위를 정리하며 제거했습니다.
