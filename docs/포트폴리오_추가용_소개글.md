# 포트폴리오 소개글

## 한 줄 소개

React·TypeScript·Konva로 구현한 브라우저 기반 카드뉴스 편집기이자 KBO 경기 결과 카드 자동 생성 도구입니다.

## 소개

이미지 업로드, 한글 문구 편집, 레이어 관리, 3가지 화면비, PNG/JPG 고해상도 내보내기와 템플릿
CRUD·JSON 이동 기능을 구현했습니다. 업로드 이미지는 서버로 보내지 않고 브라우저에서만 처리합니다.
보너스 기능으로 KBO 경기 일정을 서버리스 함수에서 정규화해 양 팀 로고·점수·경기 정보를 포함한
스코어보드 카드를 자동 생성합니다.

화면과 결과 파일이 달라지는 문제를 막기 위해 미리보기와 내보내기가 같은 Konva Stage를 사용하도록
설계했고, 잘못된 템플릿 JSON은 전체 검증 후 원자적으로 거부해 기존 작업을 보존합니다. Vercel 배포,
20개 자체 점검, 브라우저 검증과 제출용 증거 자료 제작까지 완료했습니다.

- 기술: React 19, TypeScript, Konva, Vite, Vercel Serverless Functions
- 배포: https://card-news-maker-beige.vercel.app/
- 핵심 경험: 캔버스 렌더링, 방어적 데이터 검증, 서버리스 ESM 디버깅, 반응형 편집 UX
