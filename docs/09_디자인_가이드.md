# 09. 그래픽·디자인 가이드 (2026-11-02)

앱 UI의 디자인 시스템과, 사용자가 카드뉴스에 쓸 수 있는 그래픽 도구를 정리한다.

## 1. UI 디자인 시스템

| 항목 | 내용 |
|---|---|
| 테마 | 다크(기본)·라이트. 상단 ☀/☾ 버튼 또는 명령 팔레트("테마 전환"). 선택은 브라우저에 저장되고 `<html data-theme>`로 적용된다 |
| 색 토큰 | `src/index.css`의 `--color-*`(oklch). 라이트 테마는 같은 토큰을 `:root[data-theme="light"]`에서 재정의. 캔버스 점 격자·눈금자·그림자도 토큰을 따른다 |
| 강조색 | 바이올렛→핑크 그라디언트(`--gradient-accent`), 활성 도구에는 왼쪽 표시 막대 |
| 상호작용 | 포커스 링(`:focus-visible`), 0.15s 전환, 얇은 스크롤바, 버튼 눌림 효과 |
| 아이덴티티 | 새 파비콘(`public/favicon.svg`, 겹친 카드 + 하트), 문서 제목·설명·`theme-color`, `lang="ko"` |

## 2. 그래픽 도구

| 기능 | 위치 | 설명 |
|---|---|---|
| 그라디언트 배경 | 아무것도 선택하지 않았을 때 속성 패널 → 캔버스 배경 | 단색/그라디언트, 두 색·각도, 프리셋 12종(오로라·선셋·오션·미드나잇 등), "모든 슬라이드에 적용" |
| 그라디언트 도형 | 도형 속성 → 채우기 | 모든 도형에 적용. 도형 추가 때 "그라디언트로 추가"도 가능 |
| 벡터 도형 | 도형 탭 | 사각형·둥근 사각형·원(타원)·별·삼각형·구분선 + **하트·말풍선·화살표·번개·북마크·마름모·구름·체크·더하기·리본**(SVG 경로, 비율 조절 가능) |
| 그림자 | 텍스트 외 모든 레이어의 속성 → 공통 → 그림자 | 색·번짐·가로/세로 오프셋 (텍스트는 텍스트 패널의 그림자) |
| 이미지 모양 | 이미지 속성 → 모양 | 모서리 둥글기, 테두리 색·두께 |
| 텍스트 스타일 프리셋 | 텍스트 탭 | 헤드라인·서브헤드·본문·캡션·큰 숫자·인용구·아웃라인·그림자 제목·**배지·형광펜**(도형+글자가 그룹으로 추가됨). 배경 밝기에 맞춰 글자색 자동 |
| 글자 간격·줄 간격 | 텍스트 속성 | 슬라이더 |
| 디자인 템플릿 | 갤러리 | 그라디언트·도형·그림자를 쓴 8종(오로라 인용구, 글래스 헤드라인, SALE 배너, 후기 말풍선, D-DAY, 하트 감성, 스와이프 안내, 번개 팁) + 캐러셀 세트 표지(그라디언트·장식 원) |

## 3. 구현 메모

- 그라디언트 각도는 CSS와 같다(0°=아래→위, 90°=왼쪽→오른쪽). `features/design/gradients.ts`의 `konvaGradient`가 상자 대각선에 맞춰 Konva 시작·끝 점을 계산하고, 썸네일은 `cssGradient`를 쓴다.
- Konva는 `fill`이 있으면 그라디언트보다 우선하므로 그라디언트가 있을 때는 `fill`을 전달하지 않는다.
- 경로 도형은 100×100 좌표계로 그린 뒤 레이어 크기만큼 scale한다(`strokeScaleEnabled=false`로 테두리 두께 유지). 크기 조절은 scale에서 곧바로 width/height를 읽는다.
- 그림자 색은 `rgba()`로 저장한다(Konva가 8자리 hex를 보장하지 않음).
- 템플릿 가져오기 검증은 새 선택 필드(그라디언트·그림자·이미지 모서리/테두리·도형 종류)의 형식과 범위를 모두 확인한다.

## 4. 한계

- 텍스트 자체의 그라디언트 채우기, 이미지 마스크(도형으로 자르기), 블러 배경은 아직 없다.
- 썸네일(갤러리·슬라이드 목록)은 CSS 근사라 이미지 필터·자르기 확대는 반영되지 않는다. 실제 결과는 캔버스·내보내기 미리보기를 기준으로 본다.
