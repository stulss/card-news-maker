# 11. 상용화 준비 체크리스트 (v1.0.0, 2026-11-02)

> "상용화 가능한 수준"을 **운영 품질**(라이선스·개인정보·보안·안정성·테스트)로 해석했다. 광고·결제·구독 같은 **수익화 기능은 만들지 않는다**(`CLAUDE.md` §5).

## 2. 운영자가 직접 해야 하는 일 (코드로 해결 불가)

1. **`public/legal/privacy.html`·`terms.html`의 `[서비스 운영자 이름 또는 상호]`, `[문의 이메일]`을 실제 값으로 교체.** (두 파일에 "운영 전 확인 필요" 상자가 있다 — 채운 뒤 지운다.)
2. **두 문서를 법률 전문가가 검토.** 초안은 서비스의 실제 동작 기준으로 썼지만 법률 자문이 아니다.
3. **프로젝트 자체의 라이선스 결정**(`LICENSE` 파일). 지금은 없음 = 기본적으로 모든 권리 유보.
4. **Vercel 설정 확인**: 프로젝트가 Hobby 플랜이면 상업적 서비스에는 약관상 Pro가 필요할 수 있다(Vercel 약관 확인).
5. AI 모델을 다른 것으로 바꾸면 라이선스를 다시 확인(현재 MODNet = Apache-2.0).
6. 서비스 형태가 바뀌면(로그인·분석·광고) 개인정보 처리방침을 **먼저** 고친다.

## 3. 구현 상세

### 3-1. 라이선스
- `scripts/generate-notices.mjs`가 `package-lock.json`의 운영 의존성을 읽어 라이선스 표·전문을 만든다. 허용: MIT·ISC·BSD-2/3·Apache-2.0·0BSD·CC0·BlueOak·OFL·Unlicense·Python-2.0. 그 밖이면 `prebuild`가 실패한다.
- Node 전용(`sharp`, `@img/*`, `onnxruntime-node`)은 번들에 들어가지 않으므로 제외한다 — `dist`에서 libvips/sharp 문자열이 없음을 확인했다.
- 글꼴은 모두 SIL OFL 1.1(상업 이용·결과물 배포 허용, 글꼴 단독 재판매 금지).

### 3-2. 개인정보 — 글꼴 자체 호스팅
- Google Fonts 링크 제거 → `@fontsource/*` 패키지를 `src/fonts.ts`에서 가져온다. 이모지는 `Noto Color Emoji`(OFL)로 OS 의존을 줄였다.
- `vite.config.ts`의 `dropWoffFallback` 플러그인이 `.woff` 대체 파일을 빼서 배포물을 79MB → 51MB(약 1030개 파일)로 줄였다. 이 중 26MB는 AI용 onnx wasm.
- 캔버스는 유니코드 범위로 쪼개진 글꼴이 실제 글자로 로드되도록 `document.fonts.load(…, 레이어 문구)`로 불러온다.

### 3-3. 보안 — CSP (`vercel.json`)
- `script-src 'self' 'wasm-unsafe-eval' blob:` — Transformers.js(onnxruntime-web)가 wasm 로더를 **blob: 스크립트**로 만들어 불러서 `blob:`이 필요하다(트러블슈팅 25).
- `connect-src`는 모델 내려받기용 `huggingface.co`·`*.hf.co`·`cdn.jsdelivr.net`만 추가 허용. `img-src`는 `data: blob:`, `object-src 'none'`, `frame-ancestors 'none'`.
- `style-src 'unsafe-inline'`은 Konva·React 인라인 스타일 때문에 유지(스크립트 인라인은 허용하지 않음).
- `scripts/serve-dist.mjs`는 `dist/`를 `vercel.json`과 같은 헤더로 로컬에서 띄운다 → **운영과 같은 CSP로 테스트**할 수 있다.

### 3-4. 데이터 보호
- `src/features/project/projectFile.ts`: `.cardnews.json`(슬라이드·사진 전부, 최대 300MB). 열 때 템플릿 가져오기와 **같은 검증기**로 레이어 필드를 확인하고, 잘못되면 현재 작업을 유지한 채 이유를 알려 준다(허용 목록 밖 `blendMode` 같은 악성 값 거부 확인).
- `src/features/privacy/clearData.ts`: `card-news-*` localStorage·IndexedDB·캐시 삭제. 메뉴(☰) → "저장된 모든 데이터 지우기".

### 3-5. PWA
- `public/manifest.webmanifest`(standalone), `public/sw.js`(화면은 네트워크 우선·실패 시 캐시, `/assets/*`는 캐시 우선, 외부·법적 페이지는 건드리지 않음). 등록은 운영 빌드에서만(`main.tsx`).
- 아이콘은 `npm`이 아니라 `node scripts/make-icons.mjs`(sharp, `public/favicon.svg` 기준)로 다시 만든다.
- `sw.js`의 `CACHE` 이름(`card-news-shell-v1`)은 캐시 구조를 바꿀 때 올린다.

### 3-6. 테스트·CI
| 명령 | 내용 |
|---|---|
| `npm test` | Vitest 14개 — 그라디언트, ZIP, 덱/이력 요약, 프로젝트 파일 왕복·거부, 템플릿 검증(대조군 포함) |
| `npm run test:e2e` | Playwright 3개 — 운영 빌드에서 CSP 위반 0건·외부 요청 0건, 메뉴 대화상자, 보안 헤더·법적 페이지 200 (먼저 `npm run build`) |
| `npm run verify` | lint → tsc → 라이선스 → 단위 테스트 → 빌드 → e2e 전부 |
| `.github/workflows/ci.yml` | push/PR마다 위 항목 + `npm audit --omit=dev --audit-level=high` |

로컬 Playwright는 설치된 Chrome(`channel: "chrome"`)을 쓰고, CI는 `playwright install chromium`을 쓴다.

## 4. 알려진 한계 / 다음 후보
- 법적 문서는 초안. 운영자 정보·법률 검토 필요(§2).
- AI 기능은 첫 사용 때 약 25MB를 내려받는다(모바일 성능·메모리 미검증).
- 스크린 리더로 캔버스 내용을 읽을 수 없다(캔버스 기반 편집기의 구조적 한계) — 대체 텍스트 편집 UI는 후보.
- 오류 추적(Sentry 등)은 **외부 전송이므로 넣지 않았다**. 도입하려면 개인정보 처리방침·CSP를 먼저 고친다.
- 번들 청크 500kB 경고(코드 분할)는 비차단.
