# 카드뉴스 메이커
브라우저 기반 무설치 다기능 카드뉴스·밈 제작 도구

「React-Konva 기반 웹 에디터」 과제 제출 · 발표자료

GitHub: https://github.com/stulss/card-news-maker

---

## OVERVIEW
### 프로젝트 개요

▸ **목적**: 무거운 그래픽 툴 없이, 브라우저만으로 고품질 카드뉴스를 제작
▸ **핵심 기능**:
  · 텍스트/이미지 레이어 자유 배치 및 실시간 스타일링
  · 1:1, 4:5, 9:16 인스타그램/릴스 최적화 비율 실시간 전환
  · 순수 React + Konva 캔버스 편집기 (서버 없음)
▸ **기술 스택**: 순수 HTML/CSS/JS (React, Vite, Konva)
▸ **과제 완료기준 20항목 — 전부 충족**

## CARD 1 · 편집과 미리보기
### 입력 즉시 반영되는 직관적 UI

▸ PNG/JPEG 로컬 이미지 업로드 지원
▸ 한글 문구 자유 배치 및 실시간 서식 반영
▸ 텍스트의 **위치, 크기, 색상, 외곽선(Stroke)** 등 모든 변경 사항이 지연 없이 화면(Canvas)에 실시간 반영됨
▸ 잘못된 형식(GIF 등)의 파일 업로드 시 기존 작업 상태를 보존하고 오류 안내 배너 표시

*(이 슬라이드에 편집기 UI에서 텍스트 색상과 외곽선을 조절하는 화면 캡처 첨부)*

## CARD 2 · 화면과 파일의 일치
### "보이는 그대로 저장되는" 고해상도 출력

▸ 1:1, 4:5, 9:16 세 가지 캔버스 비율 원클릭 선택 및 즉시 미리보기
▸ 화면에 표시된 미리보기 레이아웃 ↔ 다운로드된 결과물 파일 배치의 **완벽한 일치(100%)**
▸ 고해상도 출력: `pixelRatio: 1 / scale` 방식을 도입하여 기준 해상도(1080px)로 내보낼 때 텍스트 흐림이나 이미지 깨짐 현상 방지
▸ PNG 및 JPG 포맷 다운로드 지원

*(이 슬라이드에 1:1, 4:5, 9:16 비율 미리보기 화면과, 다운로드 받은 1080px 파일 결과물 비교 스크린샷 첨부)*

## CARD 3 · 극단 입력 12개 검사표 & 결함 수정
### 극단적 입력 환경 검증 전/후

| 검사 항목 (극단 입력) | 결과 | 검사 항목 (극단 입력) | 결과 |
|---|---|---|---|
| 매우 긴 한글 문장 | 자동 줄바꿈/잘림 방어 | 빈 텍스트 입력 | 기본 텍스트 삽입 |
| 한/영/숫자 혼합 문자 | 폰트 깨짐 없음 | 이모지 폭탄 입력 | Konva 렌더링 유지 |
| 여러 줄 강제 줄바꿈 | 행간격 정상 유지 | 투명 PNG 이미지 | 투명도(Alpha) 보존 |
| 가로로 매우 긴 이미지 | 캔버스 비례 축소 | 세로로 매우 긴 이미지 | 캔버스 비례 축소 |
| 초거대 해상도 이미지 | 메모리 누수 방어 | 캔버스 밖으로 레이어 이탈 | 좌표 제한/클리핑 |
| 외곽선 두께 극한값 | 렌더링 성능 유지 | 폰트 크기 극한값 | 레이아웃 박스 유지 |

▸ **결함 발견 및 수정 1건**: 텍스트에 굵은 외곽선(Stroke) 적용 시 글자가 뭉개지는 현상을 발견하여 Konva의 `fillAfterStrokeEnabled` 옵션을 적용해 글자 뭉개짐 해결 (수정 전/후 증거 확보)

*(이 슬라이드에 외곽선 결함 수정 전/후 스크린샷 증거 첨부)*

## CARD 4 · 실제 템플릿 관리 (CRUD)
### 데이터 보존과 로컬 스토리지 동기화

▸ 사용자가 만든 레이아웃을 고유한 템플릿으로 **생성(Create)** 및 **불러오기(Read)**
▸ 기존 템플릿 데이터의 **수정(Update)** 및 **삭제(Delete)** 완벽 지원
▸ `localStorage`를 활용하여 새로고침(F5)을 하거나 브라우저를 껐다 켜도 사용자의 템플릿이 100% 보존됨
▸ 생성·수정·삭제 결과가 데이터 스토어(Zustand)에 원자적으로 반영되어 화면에 즉시 동기화됨

*(이 슬라이드에 템플릿 패널에서 템플릿을 저장하고 불러오는 목록 화면 스크린샷 첨부)*

## CARD 5 · 엣지케이스 방어 (JSON 및 완성품)
### JSON 입출력과 저작권 클리어 완성본

▸ 템플릿 JSON **내보내기(Export) / 가져오기(Import)** 지원
▸ **비정상 JSON 2종 방어 테스트 통과**:
  1. 구조 오류(Syntax Error) 파일: 파싱 실패 후 기존 데이터 안전하게 보존
  2. 필수값 누락(Missing Fields) 파일: 유효성 검사에서 걸러내어 로드 거부 및 에러 표출
▸ **완성 이미지 산출물**: 
  · 개인정보/비밀값 하드코딩 0건 (저장소 grep 전수 검사 통과)
  · EXIF 데이터가 제거된 저작권 클리어 완성본 이미지 3개 산출 완료

*(이 슬라이드에 비정상 JSON 파일을 불러왔을 때 뜨는 에러 배너와 최종 완성본 이미지 3종 첨부)*

## TECH DECISION
### 복잡한 DOM 대신 React-Konva를 선택한 이유

“이 서비스의 화면은 정적인 결과물인 이미지를 픽셀 단위로 정확히 구성해야 한다. 
DOM 렌더링을 캡처(html2canvas)하면 해상도와 브라우저별 렌더링 편차가 커져 '미리보기와 결과물이 다른' 치명적 결함이 생긴다.”

▸ **Canvas (React-Konva)** 선택
  · **장점**: 화면에 보이는 결과와 `toDataURL`을 통한 추출 결과가 픽셀 단위로 100% 일치
  · **장점**: 텍스트 외곽선, Z-Index 등 그래픽 요소 제어가 네이티브 수준으로 정밀함

## AI 3줄
### 맡긴 일 · 판단한 일 · 말을 안 들은 일

▸ **AI에게 맡긴 일**: 
React-Konva 아키텍처 작성, JSON 파서 에러 엣지케이스 방어 코드 작성 및 Chrome CDP 기반의 백그라운드 실시간 렌더링 테스트/검증 수행.
▸ **내가 판단한 일**: 
`localStorage`에 저장될 템플릿 스키마 구조의 설계 및 로고 처리 정책 수립.
▸ **AI 말을 안 들은 일**: 
AI가 SSR 백엔드 기능으로 서비스 확장을 제안했으나 과제 스펙을 넘어서므로 반려함. 또한 텍스트 외곽선이 뭉개지는 현상에 대해 AI는 폰트 문제라고 했으나, 직접 Konva `stroke` 옵션을 찾아내어 `fillAfterStrokeEnabled` 적용을 지시함.

## VERIFICATION GUIDE
### 검증 안내서 — 직접 확인하는 방법 (3단계)

1. **접속 후 비율/이미지 선택**
   ▸ 프로젝트 URL로 접속하여 캔버스 비율(1:1, 4:5, 9:16)을 누르고, 배경 이미지를 업로드해 본다.
2. **텍스트 수정 및 템플릿 저장**
   ▸ 텍스트의 크기와 외곽선을 조정하고, 우측 템플릿 탭에서 '현재 상태 저장' 버튼을 눌러 목록에 추가한다. 그 후 브라우저 새로고침(F5)을 해본다.
3. **1080x1080 PNG/JPG 다운로드**
   ▸ '다운로드' 버튼을 눌러 결과 이미지가 미리보기와 일치하는지 확인한다.
