## OVERVIEW
### 프로젝트 개요

▸ **목적**: 무거운 그래픽 툴 없이, 브라우저만으로 고품질 카드뉴스와 야구 스코어보드를 제작
▸ **핵심 기능**:
  · 텍스트/이미지 레이어 자유 배치 및 실시간 스타일링 (외곽선, 정렬, 폰트)
  · 1:1, 4:5, 9:16 인스타그램/릴스 최적화 비율 실시간 전환
  · KBO 야구 스코어보드 자동 템플릿 생성 (워터마크, 비율 보존)
▸ **기술 스택**: 순수 React + Konva (서버 없이 100% 클라이언트 사이드 동작)
▸ **데이터 보존**: `localStorage`를 활용한 템플릿/레이어 실시간 저장 및 복구

**과제 완료기준 20항목 — 100% 충족**

## CARD 3 · 야구 스코어보드 자동화
### 완벽한 비율과 Z-Index 컨트롤 (기능 확장)

▸ 팀 선택 및 점수 입력만으로, 팀 상징색에 맞춘 배경과 워터마크를 자동으로 렌더링
▸ **로고 비율 보존**: 구단별로 서로 다른 엠블럼 비율(1:1, 타원, 직사각형)을 `contain` 방식으로 찌그러짐 없이 안전하게 렌더링
▸ **심플한 텍스트 & 대형 워터마크 레이아웃**: 시인성을 높이기 위해 배경 워터마크 불투명도 세밀 조정 (0.15~0.3)
▸ **Z-Index 설계**: 배경 레이어(0, 0.1)와 워터마크 레이어(1.5, 1.6)를 명확히 분리하여, 겹침 없이 정확하게 표현

## TECH DECISION
### 복잡한 DOM 대신 React-Konva를 선택한 이유

“이 서비스의 화면은 정적인 결과물인 이미지를 픽셀 단위로 정확히 구성해야 한다. 
HTML/CSS DOM 렌더링을 후처리로 캡처(html2canvas)하면 해상도와 브라우저별 렌더링 편차가 커져 '미리보기와 결과물이 다른' 치명적 결함이 생긴다.”

▸ **Canvas (React-Konva)** 선택
  · **장점**: 화면에 보이는 렌더링 결과와 `toDataURL`을 통한 추출 결과가 픽셀 단위로 100% 일치
  · **장점**: 텍스트 외곽선(Stroke), 이미지 크롭(Cover), Layer Z-Index 등 그래픽 요소 제어 용이
  · **최소 전송 크기**: 무거운 서버 사이드 렌더러 없이 JS 번들만으로 동작

## TROUBLESHOOTING
### 실제로 겪은 문제 2건 중 대표 사례

**1. 워터마크가 한쪽(오른쪽)만 보이지 않는 현상**
▸ **원인**: 좌/우 배경색 레이어의 Z-Index를 각각 `0`과 `1`로 다르게 부여함. 이때 오른쪽 배경색(1)이 양쪽 워터마크(0.5, 0.6)보다 높아서, 오른쪽 워터마크를 완전히 덮어버림.
▸ **해결**: 워터마크 Z-Index를 `1.5`, `1.6`으로 올려 배경 위로 안전하게 노출되도록 수정. (코드 수정 2줄)

**2. 특정 구단 로고 워터마크 식별 불가 현상**
▸ **원인**: 삼성, SSG 등 구단 로고 이미지의 색상이 팀 배경색과 완벽히 일치하여 투명도를 주면 묻힘.
▸ **해결**: 워터마크 투명도(`opacity`)를 상향 조절하여 윤곽선이 식별되도록 방어 처리.
